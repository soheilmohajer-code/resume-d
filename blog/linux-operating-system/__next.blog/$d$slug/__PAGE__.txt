When I started self-hosting my automation stack (the same journey from my
<a href="/blog/docker-production-guide/">Docker guide</a>), the server handed to me ran

terminal and a blinking cursor. It looked hostile. Six months later, it had
become the environment I trust most.</p>
<p>This post is the explanation I wish I&#39;d read on day one: what Linux actually
is (the word is used for at least three different things), how it really
differs from Windows and macOS, an honest list of where it wins and where it
loses, and the surprising answer to &quot;how popular is it, really?&quot;</p>
<blockquote>
<p><strong>TL;DR</strong> — Linux is a free, open-source kernel that anyone can build an
operating system around. It dominates servers, supercomputers, Android
phones and the cloud, struggles on the consumer desktop (gaming and
industry software), and rewards the effort with control nothing else
offers.</p>
</blockquote>
<h2 id="what-linux-actually-is">What Linux actually is</h2><p>The first surprise: <strong>Linux is not an operating system.</strong> Strictly speaking,
Linux is a <em>kernel</em> — the core program that talks to your hardware (CPU,
memory, disk, network) and lets software run. What people call &quot;Linux&quot; in
daily conversation is almost always a <strong>distribution</strong> (distro): a complete
operating system assembled from the Linux kernel plus GNU tools, a desktop
environment, a package manager and thousands of applications.</p>
<p>That&#39;s the second surprise: there is no single Linux. Anyone can take the
kernel and build their own OS around it, and people have — thousands of
times. Ubuntu, Debian, Fedora, Arch, Mint, Red Hat… they are all &quot;Linux&quot;,
yet they feel different, the way two cars with the same engine can be
completely different vehicles.</p>
<p>And the third: it&#39;s <strong>free and open source</strong>. Not &quot;free trial&quot; free — the
source code is public, licensed so that anyone can read it, modify it,
redistribute it, and even sell their version. No license activation, no
account requirement, no telemetry you can&#39;t turn off.</p>

<p>The deepest difference isn&#39;t in the table though — it&#39;s the <strong>philosophy</strong>:</p>
<ul>
<li><strong>Windows</strong> is designed for the masses: hardware vendors decide, you
click through wizards, the system hides its internals. Great when it
works; a black box when it doesn&#39;t.</li>
<li><strong>macOS</strong> is designed for a curated experience: Apple controls hardware
and software, so everything fits — as long as you stay inside the garden.</li>
<li><strong>Linux</strong> is designed for <strong>control</strong>. Nothing is hidden from you. Every
config is a text file you can read and change. If you want to know what
runs at boot, you look; if you want to replace the desktop, the shell,
even the kernel itself — you can.</li>
</ul>

think about software. On Windows, installing an app means visiting a
website, downloading an installer, and hoping it&#39;s not bundled with junk.
On Linux:</p>

<h2 id="where-linux-wins">Where Linux wins</h2><ul>
<li><strong>Free, truly.</strong> No license, no activation, no subscription. Install it
on one machine or a thousand.</li>
<li><strong>Performance and longevity.</strong> A lightweight distro turns a 15-year-old
laptop into a usable machine. The same OS scales from a router to the
world&#39;s biggest servers.</li>
<li><strong>Stability.</strong> Servers routinely measure uptime in <em>years</em>. There&#39;s a
reason &quot;it&#39;s been up for 400 days&quot; is a Linux brag.</li>
<li><strong>Security model.</strong> Open code that thousands of eyes review, strict
user/permission separation, and a malware landscape that is tiny compared
to Windows (smaller user base on desktop, and central repos instead of
random installers).</li>
<li><strong>Privacy.</strong> No account required, no telemetry you can&#39;t disable, no ads
in the start menu.</li>
<li><strong>The terminal.</strong> Once you learn it, the shell is a superpower — every
task scriptable, every server reachable, every fix a copy-paste away.</li>
<li><strong>The ecosystem for developers.</strong> Native package managers, the same
environment as your production servers, and every language and tool
installed with one command.</li>
</ul>
<h2 id="where-linux-loses-the-honest-part">Where Linux loses (the honest part)</h2><ul>
<li><strong>Industry software doesn&#39;t exist there.</strong> No native Adobe Photoshop /
Premiere, no native Microsoft Office, no SolidWorks. Workarounds exist
(web versions, Wine/VMs), but if your livelihood depends on one of
these, that&#39;s the dealbreaker.</li>
<li><strong>Gaming is better but not equal.</strong> Thanks to Valve&#39;s Proton, the Steam
Deck runs Windows games on Linux impressively well — most games with
anti-cheat or DRM still refuse, though. Check
<a href="https://areweanticheatyet.com">areweanticheatyet.com</a> before switching
for gaming.</li>
<li><strong>Hardware quirks.</strong> Most hardware &quot;just works&quot; today, but some Wi-Fi
chips, printers and NVIDIA GPUs still need extra drivers or patience.
Check compatibility <em>before</em> installing on laptops.</li>
<li><strong>Fragmentation.</strong> Thousands of distros, several package managers, docs
that say &quot;on Debian do X, on Arch do Y&quot;. Freedom has a coordination cost.</li>
<li><strong>The learning curve is real.</strong> You <em>can</em> use Ubuntu like Windows, but
the moment something breaks, the answers live in the terminal. That&#39;s a
feature for some of us and a wall for others.</li>
<li><strong>Help is community-based.</strong> No Microsoft support line; you get forums,
wikis and Discord servers — usually excellent, occasionally humbling.</li>
</ul>
<h2 id="how-popular-is-it-really">How popular is it, really?</h2><p>On the desktop, modest: around <strong>4%</strong> of computers (statcounter, 2026) —
but that number hides where Linux actually lives:</p>
<ul>
<li><strong>Supercomputers: 100%.</strong> Every single machine in the TOP500 list runs
Linux. Not most — <em>all</em> of them.</li>
<li><strong>Servers and the cloud: dominant.</strong> The majority of web servers, and
roughly 90% of public cloud workloads, run on Linux.</li>
<li><strong>Android: ~3 billion devices.</strong> Android is built on the Linux kernel —
it&#39;s the most used &quot;Linux&quot; on Earth, it just doesn&#39;t wear the name.</li>
<li><strong>Everything embedded.</strong> Routers, smart TVs, cars, Raspberry Pis,
satellites, in-flight entertainment… Linux is the default OS of things
that aren&#39;t computers.</li>
<li><strong>Windows runs Linux now.</strong> WSL (Windows Subsystem for Linux) puts a
real Linux environment inside Windows — Microsoft&#39;s quiet concession to
where development actually happens.</li>
<li><strong>Steam Deck.</strong> Valve&#39;s handheld runs SteamOS, a Linux distro — the
biggest consumer-desktop push in years.</li>
</ul>
<p>So the fair summary: Linux lost the desktop war and won everything else.</p>
